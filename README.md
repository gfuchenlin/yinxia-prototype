# 音匣 · HTML 交互原型

每个屏幕一个 HTML 文件，不再用设计 PNG 贴图。

## 打开方式

用浏览器打开 `index.html`，或从启动页进入主路径：

```bash
python3 -m http.server 8765 --directory .
```

然后访问 `http://127.0.0.1:8765/pages/splash.html`。

## 主路径（CR-003 已锁）

**冷启动一律：**

`启动页 → 选择服务 → 连接配置 → 连接成功 → 曲库`

- **禁止**启动页直达曲库（即使本机已保存过资料库，原型演示仍走完整连接链路，便于验收）。
- 已登录态的工程实现可另议；**原型文档与可点路径不得写成直达。**

## 曲库

3 列六宫格：歌曲 / 我喜欢的 / 本地音乐 / 专辑 / 流派 / 歌手  
下方：「我的歌单」+「最近播放」横滑  
底栏三 Tab：搜索 / 曲库 / 设置

## 设置（五块已锁）

1. 服务器（卡片 + 断开/重连；通断细则跟 A/B/C）
2. 播放（循环列表/单曲；无独立音量行）
3. 缓存（已用 + 清除）
4. 外观（仅跟随系统）
5. 关于（Logo E + 音匣 + Slogan + 版本）
